# AIGC 公益广告 · 戒烟

### AIGC Public Service Ad · Quit Smoking

> 一支烟燃尽的不只是时间，还有本该陪伴家人的岁月。

![封面](cover.jpg)

---

## 项目概述 · Overview

本片是一部 **AIGC 公益广告**，聚焦吸烟对个人与家庭的伤害。影片讲述一位重度吸烟者因长期吸烟罹患肺癌晚期，最终失去了与女儿共同成长的时光，让整个家庭承受深深的痛苦。

影片采用**伤感而克制**的叙事手法，不靠说教与恐吓，而是用「失去」本身唤起观众的共鸣——**最打动人心的戒烟理由，往往不是「你会生病」，而是「你爱的人会失去你」。**

作为纯 AIGC 创作，本片验证了 AI 工具链在**情感类公益广告**上的表达潜力。

---

## 剧情梗概 · Storyline

1. **日常**：一位重度吸烟者常年在家里吸烟，烟雾缭绕中，他忽略了二手烟对家人的伤害；
2. **代价**：长期吸烟让他罹患肺癌，且已是晚期；
3. **失去**：病床上的他，再也无法陪女儿去游乐园、陪她长大，曾经触手可及的日常，成了再也回不去的奢望；
4. **反思**：留给家人的，只有无尽的遗憾与伤害。

---

## 主题表达 · Themes

### 二手烟的隐性伤害

影片刻意强调「在家里吸烟」这一细节——吸烟者伤害的不仅是自己，更是朝夕相处的家人，尤其是孩子。

### 失去的不可逆

肺癌晚期的设定，让「后悔」失去了意义。影片用这种不可逆，传递最有力的警示：**别等到失去，才懂得珍惜。**

---

## 视觉风格 · Visual Style

- **生活场景**：以家庭日常的温馨，反衬吸烟带来的阴影，形成强烈反差；
- **色调变化**：从起初的暖调生活，逐步过渡到病房的冷调压抑，映射健康与亲情的消逝；
- **情感留白**：以克制的镜头语言，把「遗憾」留给观众自己体会。
